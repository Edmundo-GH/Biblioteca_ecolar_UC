# Sistema de Gestión de Biblioteca Escolar

Aplicación de escritorio en Python para automatizar la gestión de una biblioteca escolar: préstamos, servicios, KPIs y exportación a Excel.

Los archivos CSV incluidos son **plantillas de ejemplo (datos ficticios)**. Para usarlo en producción, reemplázalos con tus datos reales.

## Características

* **Préstamos:** Registro rápido por folio e importación desde AppSheet.
* **Servicios:** Estancias, lectura, ajedrez, eventos grupales y búsqueda inteligente (fuzzy search).
* **Reportes:** Índice lector, Top de lectores, Lista de deudores con correos y gráficas interactivas.
* **Persistencia:** Guardado automático en memoria local.

## Tecnologías

* Python 3.10+
* CustomTkinter
* Pandas
* OpenPyXL
* Matplotlib
